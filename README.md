# Simple voice recorder - ESP32-based



<img width="722" height="581" alt="image" src="https://github.com/user-attachments/assets/3a161db8-a267-40c3-ae14-c5142762b3e8" />


## Why
Making a durable, easy-to-use voice recorder for my mom's classroom with a cool UI screen. No loose wires for small children to break.

## Parts
* Ideaspark ESP32 with 1.14" ST7789 TFT
* INMP441 I2S Mic Breakout
* SPI Micro SD Module + Card
* Big home limit switches
* Sockets, resistors, caps
<img width="564" height="701" alt="image" src="https://github.com/user-attachments/assets/8f2ad14d-2a28-4a2b-bf9c-86e6f9d1879d" />

## Plan
1. Route SPI/I2S once the JLCPCB KiCad board gets here
2. Plug modules into 2.54mm sockets
3. Solder switches via wires
4. Do code stuff in Arduino IDE
